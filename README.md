# 카드 가계부 (Card Budget Dashboard)

**바로 쓰기 → https://nohhyunwook.github.io/card-budget/**

폰 브라우저로 위 주소를 열고, 크롬이면 주소창 오른쪽 ⋮ → **앱 설치 / 홈 화면에 추가**, 아이폰 사파리면 공유 → **홈 화면에 추가**를 누르면 아이콘으로 실행됩니다.

카드 결제예정금액 엑셀·CSV를 올리면 **분류별·카드사별·일자별 그래프와 실시간 합계**로 한눈에 보여주는 가계부 웹앱입니다.
파일 하나(HTML)로 동작하고, 입력한 자료는 **서버로 보내지 않고 내 브라우저(localStorage)에만** 저장됩니다.
(단, **📸 캡처로 추가**를 쓸 때만 올린 캡처 이미지가 내가 고른 AI 제공자에게 전송됩니다.)

## 쓰는 법

1. 아래 주소를 폰·PC 브라우저로 엽니다.
2. **⚙ 설정 → 데이터 → 파일 선택**에서 카드사에서 받은 `엑셀(.xlsx)` 또는 `CSV`를 올립니다.
   - 표에 `이용일자 / 가맹점 / 청구금액 / 분류` 머리글이 있으면 그대로 읽습니다. (분류가 비어 있으면 규칙으로 자동 분류)
   - 엑셀 해석은 최초 1회만 인터넷(CDN)이 필요합니다. CSV는 오프라인에서도 됩니다.
3. 표에서 **분류를 바꾸면 위 합계·그래프가 바로 다시 계산**되고 자동 저장됩니다.
4. 최상단 **카드별 한도** 칸을 누르면 카드사별 **월 사용액 한도**를 넣을 수 있습니다.  
   **남은 한도**(한도 − 그 달 사용액)가 바로 보이고, 한도를 넘으면 빨간색으로 표시됩니다. `전체`를 고르면 내역이 있는 가장 최근 달 기준이고, 한도는 이 브라우저(localStorage)에만 저장됩니다.  
   그 아래 **사용액 분석**은 한도 초과·근접 카드와 원인(1위 분류·가맹점), 다음 달 줄일 금액을 2~3줄로 보여 줍니다. `⚙ 설정 → AI 캡처`에 Gemini 키가 있으면 **AI 분석** 버튼으로 같은 내용을 AI가 더 간추려 줍니다(같은 달·금액이면 캐시를 써서 다시 호출하지 않습니다).
5. **일자별 추이**는 카드 사용기간(**전월 13일 ~ 당월 12일**)을 가로축으로 한 꺾은선 그래프입니다. **연간 사용액**은 그 해 총액을 보여 주고, **카드사** 칩으로 카드별 연간 추이만 따로 볼 수 있습니다.
   처음 열면 **접속한 날이 속한 카드 사용기간의 결제월**(13일 이후면 다음 달)이 자동으로 선택됩니다.
6. 필요하면 **⬇ CSV**로 내보내고, **JSON 백업**으로 기기 이동·복원을 합니다.
7. 폰에서 카드사 앱·웹 사용내역을 캡처했다면 **📸 캡처로 추가** → 이미지 선택 → **분석하기** → 확인 후 **선택 내역 추가**. (아래 설명)
8. 다른 사람에게 앱만 줄 때는 아무 자료도 올리지 않은 상태로 주소만 알려주면 됩니다. (이 저장소에는 개인 내역이 없습니다)

## 📸 캡처로 내역 추가 (AI)

카드사 앱·웹의 **사용내역 · 결제예정금액 화면을 캡처**해 올리면 AI가 거래(날짜·가맹점·금액·카드사·비고)를 읽어 내역으로 만들어 줍니다.

1. **⚙ 설정 → AI 캡처**에서 제공자를 고르고 API 키를 넣습니다.
   - **Google Gemini** (추천 · 무료 티어 가능): https://aistudio.google.com/apikey
   - **OpenAI (GPT)**: https://platform.openai.com/api-keys — 결제(크레딧)가 등록된 키가 필요합니다.
   - 키는 **이 브라우저(localStorage)에만** 저장되고, JSON 백업·동기화 파일에는 들어가지 않습니다.
2. 상단 **📸 캡처** 또는 상세내역의 **📸 캡처로 추가**를 누르고 이미지를 고릅니다(여러 장 가능, 최대 10장).
3. 카드사(자동 인식 또는 직접 선택)와 반영할 결제 월을 고르고 **분석하기**를 누릅니다. 보통 2~5초 걸립니다.
4. 추출된 내역을 확인하고 가맹점·날짜·금액·분류를 고친 뒤 **선택 N건 추가**를 누르면 합계·그래프·상세내역에 바로 반영됩니다.

**중복은 자동으로 걸러집니다.**
- 여러 장이 겹쳐 찍혀 같은 거래가 두 번 보여도 한 번만 잡습니다.
- 이미 가계부에 있는 내역은 **날짜 + 가맹점명(공백·`(주)` 표기 차이 무시) + 금액**이 같으면 자동으로 제외하고, `중복 N건 자동 제외됨` 배지로 몇 건이 빠졌는지 알려줍니다. 펼쳐서 필요하면 직접 체크해 추가할 수 있습니다.
- 새 내역만 체크된 상태로 나오므로 그대로 **선택 N건 추가**를 누르면 됩니다.


## 홈 화면에 추가 (앱처럼 쓰기)

- **안드로이드 크롬**: 주소창 오른쪽 ⋮ → **앱 설치** / **홈 화면에 추가**
- **아이폰 사파리**: 공유 → **홈 화면에 추가**

한 번 추가해두면 아이콘을 눌러 바로 열 수 있고, 전체화면(standalone)으로 실행됩니다.

## 자동 최신화 (선택)

상단 **🔄 새로고침**을 누르면 캐시를 무시하고 최신 자료를 다시 받아옵니다. 화면 위에 `마지막 동기화` 시각이 표시됩니다.

**⚙ 설정 → 동기화**에 JSON 주소를 저장해두면 앱을 열 때마다 자동으로 최신 JSON을 받아와 합칩니다.

- 공개 JSON 주소: 그대로 입력
- GitHub 비공개 저장소: `https://api.github.com/repos/아이디/저장소/contents/data` 형식 + `Contents: Read-only` 권한의 fine-grained 토큰

같은 곳에 `rules.json`(내 자동 분류 규칙)이 있으면 데이터 파일보다 **먼저** 읽어 그 규칙으로 분류합니다.
내 단골 가맹점·개인 분류는 이렇게 비공개 저장소 쪽에만 두면, 공개된 앱에는 남지 않습니다.

JSON 형식은 **데이터 → JSON 백업** 파일과 같습니다.

```json
{ "rows": [ { "month": "2026-11", "card": "삼성카드", "date": "2026-10-14", "merchant": "쿠팡", "amount": 12000, "category": "생활비" } ] }
```

## 내 분류 규칙은 비공개 저장소에 (rules.json)

앱에 들어 있는 기본 분류·자동 분류 규칙은 **누구나 쓸 수 있는 범용 예시**입니다
(`주유·충전`, `하이패스·통행료`, `생활공과금`, `보험료`, `용돈`, `생활비`, `기타`).

내 단골 가맹점 이름이나 개인적인 분류는 공개 저장소에 넣지 말고, 동기화용 **비공개 저장소**의 같은 폴더에
`rules.json` 으로 둡니다. 앱은 동기화할 때 데이터 파일보다 먼저 이 파일을 읽어 적용합니다.

```json
{
  "replaceCategories": true,
  "categories": [
    { "name": "생활비", "color": "#3b82f6" },
    { "name": "용돈", "color": "#f59e0b" },
    { "name": "기타", "color": "#94a3b8" },
    { "name": "내 차량", "color": "#10b981" }
  ],
  "rules": [
    { "category": "내 차량", "keywords": ["충전소", "주유소"], "min": null, "max": null },
    { "category": "용돈", "keywords": ["내 단골 카페"], "min": null, "max": 10000 }
  ]
}
```

- `rules`는 위에서부터 먼저 맞는 규칙 하나가 적용됩니다. `keywords`는 가맹점 이름에 들어 있는 글자, `min`/`max`는 금액 범위(원)입니다.
- `categories`와 `"replaceCategories": true`를 넣으면, 앱의 기본 분류 중 이 파일에 없고 쓰이지도 않는 것만 정리됩니다. 내가 앱에서 직접 만든 분류와 이미 쓰인 분류는 그대로 둡니다.
- 이 파일이 있으면 앱 화면에서 직접 고친 규칙보다 이 파일이 우선합니다. 규칙은 이 파일에서 고치는 것이 기준입니다.
- 이 파일이 없으면 앱은 기본 범용 규칙으로 분류합니다.

## 개인정보

- 이 저장소에는 **어떤 개인 결제내역도 들어 있지 않습니다.** 초기 내역이 빈 공용 버전입니다.
- 기본 분류 규칙에도 특정인의 단골 가맹점·차종 같은 개인 정보가 들어 있지 않습니다.
- 앱이 저장한 결제 자료는 사용자의 브라우저에만 남고, 어떤 서버로도 전송되지 않습니다.
- **📸 캡처로 추가**를 쓸 때만, 올린 캡처 이미지가 사용자가 고른 AI 제공자(Google Gemini / OpenAI)에게 브라우저에서 직접 전송됩니다. 중간 서버는 없고, 이미지는 앱에 저장되지 않습니다. AI 키도 그 브라우저에만 저장됩니다.
